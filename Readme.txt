# Scoreboard Web App

A simple interactive scoreboard built with HTML, CSS, and JavaScript to track scores and fouls for two teams in real-time.

## Features
- Track HOME and GUEST scores (+1, +2, +3)  
- Track fouls for each team  
- RESET button to reset scores and fouls  
- Responsive layout with modern UI  

## Technologies Used
- HTML  
- CSS  
- JavaScript  

## How to Use
1. Open `index.html` in a browser.  
2. Click **+1, +2, +3** buttons to update scores.  
3. Click **+1 Foul** to track fouls.  
4. Click **RESET** to reset everything.
